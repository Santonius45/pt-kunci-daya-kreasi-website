# PT Kunci Daya Kreasi — Official TypeScript Website
Versi 2.0.0 — Production-Ready Single Page Application (SPA)

## Keunggulan Versi TypeScript:
- **Strict Type Checking**: Menggunakan TypeScript 5+ dengan `tsconfig.json` berstandar tinggi.
- **Visual Identity Precision**: Mengikuti presisi tinggi panduan identitas merek KDK (Deep Navy `#102C4C`, Muted Gold `#C69A4B`, Warm Ivory `#F8F7F3`).
- **Zero Heavy Dependencies**: Sangat cepat, modern, dan siap di-build dengan Vite.
- **KBLI 58110 & Perpusnas Ready**: Struktur metadata bibliografi dan URL permanen mendukung penuh pengajuan ISBN 2026.

## Cara Menjalankan secara Lokal:
1. Ekstrak arsip ZIP ini.
2. Buka terminal di dalam folder proyek `pt_kunci_daya_kreasi_ts_web`.
3. Jalankan perintah:
   ```bash
   npm install
   npm run dev
   ```
4. Buka tautan lokal yang muncul (misalnya `http://localhost:5173`).

## Cara Build untuk Production Hosting:
```bash
npm run build
```
Hasil kompilasi siap diunggah di folder `dist/`.
